# وضعیت بررسی این بسته

**این فایل تأییدیهٔ نصب تولیدی نیست.** نتیجه‌های زیر از اجرای واقعی بررسی‌های آفلاین به‌دست آمده‌اند. به GitHub push نشده، به پایگاه دانشگاه متصل نشده، و در سرور کاربر مستقر نشده است.

| بررسی | نتیجهٔ ثبت‌شده |
|---|---|
| ZIPهای ورودی | هر دو بدون خطا استخراج شدند؛ SHA-256 هر دو `cbef16faae3e5a9e0547cad1e1565a878a7a7ed205fddd0be20e76135e3b4562` و شناسهٔ کامنت `d66194d9dcc62b1edeac5a8a8e8544c34099518c`. |
| مقایسهٔ ورودی با بسته | هیچ فایل ردیابی‌شدهٔ ورودی حذف نشده است؛ هر ۹ مهاجرت قدیمی و Designer متناظر بدون تغییر. فقط Snapshot برای مدل جدید افزوده شده است. |
| Solution و referenceها | XML بررسی شد؛ ۱۱ پروژه و ۱۷ ارجاع پروژه‌ای پیدا و مسیرها تطبیق داده شدند. |
| مدل و مهاجرت | تطبیق ایستای ۳۴ جدول LMS میان موجودیت، مدل runtime، مدل frozen و مهاجرت؛ ۵۴ FK جدید NoAction، ایندکس یکتای فیلترشدهٔ پروندهٔ فعال. اجرای schema با SQL Server هنوز انجام نشده است. |
| مسیر و MediatR | تطبیق ایستای ۴۷ route جدید با ۴۵ نوع درخواست (دو مسیر جریان مستقیم) و یک مسیر قدیمی writable-scopes با `GetWritableScopesQuery`. اجرای `WorkItemsConsoleReadContractTests` هنوز انجام نشده است. |
| Excel و JavaScript | بازخوانی دو قالب بدون داده/فرمول/ماکرو، سرستون‌ها و سبک متنی بررسی شد. نحو JavaScript و رفتار آفلاین آداپتور ارسال با شبیه‌ساز `fetch`/`XHR` بررسی شد (انتقال خام، CSRF، HTTP 403/413 و قطع شبیه‌سازی‌شده). این آزمون HTTP واقعی نیست. |
| Build / Restore و xUnit | اجرا نشد؛ `dotnet --info` با `command not found` و کد ۱۲۷ متوقف شد. تست‌های حوزه و SQL در سورس هستند، اما نتیجهٔ قبولی برای آن‌ها اعلام نمی‌شود. |
| SQL Server، مرورگر علیه Web/API، WAF و پیامک | اجرا / تأیید نشده‌اند. نه نصب خالی، نه ارتقا، نه ۲۵۰ مگابایت سرتاسری و نه درگاه واقعی تأیید نشده است. |

بررسی‌های آفلاین همراه پروژه، در صورت تمایل:

```bash
python docs/check-source.py
node --check src/ReusableAccess.Web/wwwroot/js/lms-transfer.js
node docs/check-transfer.js
```

Python و Node فقط برای همین بررسی اختیاری‌اند و وابستگی برنامهٔ LMS یا Build اصلی نیستند. آزمایش SQL به پیکربندی نمونهٔ آزمایشی جدا نیاز دارد. پیش از استفادهٔ تولیدی، دورهٔ کامل [استقرار و پذیرش](DEPLOY.fa.md) را اجرا کنید.
